Open the project folder:

```bash

```

# 📌 Deployment

This portfolio can be deployed easily using **GitHub Pages**.

### GitHub Pages

1. Push the project to GitHub.
2. Open the repository.
3. Go to **Settings**.
4. Select **Pages**.
5. Choose the deployment branch.
6. Select the root folder.
7. Save the settings.
8. GitHub will generate the live portfolio URL.
